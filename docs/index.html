GuideStrap

Roblox, set up the way you like it.

GuideStrap is a launcher for Roblox on Windows. Pick your graphics, swap the death sound and cursor, switch accounts, and show what you're playing on Discord.

Free and open source. Made by guideships.

What's inside

Graphics presets

One slider from Max FPS to Max Graphics, or change every setting yourself.

FastFlags

An editor for Roblox's allowed flags. Paste JSON, and it asks before replacing ones you already have.

Mods

Custom death sound, cursors, sky packs and an in-game font.

Accounts

Log in once, then switch accounts in one click.

Discord status

Shows the game you're in, its icon and a link to it.

Server location

Tells you where the server you joined is.

Recent games

Jump back into the last games you played.

Profiles

Export your setup as a file and share it.

Auto updates

GuideStrap updates itself when a new version is out.

Questions

Can this get me banned?

GuideStrap never touches the game while it runs. It only changes files and settings Roblox reads when it starts, like Bloxstrap and Fishstrap. It isn't an exploit and doesn't give any gameplay advantage.

Does it change my normal Roblox?

No. Everything happens in GuideStrap's own copy of Roblox. Opening Roblox without GuideStrap always gives you the original game, sounds and settings.

Windows says it's unrecognized. Is that normal?

Yes, for new apps that aren't code-signed yet. Click "More info", then "Run anyway". The full source code is on GitHub if you want to check it.

Where are my saved logins kept?

On your PC only, encrypted with Windows so they only work for your Windows user. They're never uploaded anywhere.
